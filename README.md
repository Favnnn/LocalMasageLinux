# 🌉 Мост

Мессенджер для обмена **текстом, файлами, фото и видео** между компьютерами и телефонами
по локальной сети (Wi-Fi) или через VPN-туннель. Без облака, без регистраций — всё
идёт напрямую между вашими устройствами.

- `Мост.exe` — **сервер** для Windows (двойной клик → откроется веб-интерфейс).
- `Мост-клиент.exe` — **клиент-оболочка для ПК** (окно на WebView2): при запуске — экран
  выбора сервера, внутри — тот же интерфейс, что и в браузере. Кнопка ⚙ на любой странице
  возвращает к выбору сервера, «🌐» открывает чат в обычном браузере. Если WebView2 нет,
  клиент сам откроет браузер. Можно передать адрес аргументом:
  `Мост-клиент.exe most://192.168.0.100:8410`.
- `Мост.apk` — приложение для Android (8.0+): при запуске показывает **выбор сервера**,
  все добавленные серверы сохраняются (переключение в пару тапов). Веб-интерфейс также
  доступен из любого браузера.

## Возможности чата

- Текст, файлы любого типа; картинки и видео показываются прямо в чате, аудио — плеером.
- **Редактирование** своих сообщений (✏️), **удаление** любого сообщения (🗑 — файл
  стирается и с диска), **удаление whole чата** (🗑 в шапке чата или в списке комнат).
- **Создатель чата.** Кто первым вошёл в несуществующую комнату (или создал её) — тот
  создатель: только он может удалить чат целиком и удалять участников (✕ у имени в панели
  «Участники»; удалённый не сможет войти, пока создатель не вернёт его кнопкой «↩»).
- **Пароль чата.** При создании комнаты укажите пароль — без него (или с неверным) другие
  подключиться не смогут. Создатель входит всегда. Создатель — по имени, поэтому для
  надёжной защиты придумывайте пароль.
- **Скрытая комната.** Галочка «Скрытая комната» при создании: комната не показывается в
  списке «Комнаты на этом сервере» — попасть в неё можно, введя её точное имя в поле
  «Комната» (это и есть поиск).
- История сохраняется на компьютере и восстанавливается после перезапуска сервера.
- Загрузка нескольких файлов сразу, вставка из буфера (Ctrl+V), drag-and-drop на ПК.
- Скачивание файлов на телефоне — в папку «Загрузки/Мост».
- Интерфейс на русском и английском (кнопка RU/EN), тёмная тема, мобильная вёрстка.

## Быстрый старт

1. Запустите `Мост.exe` на компьютере. В консоли появится список адресов, браузер откроется сам.
2. На телефоне: тот же Wi-Fi → приложение «Мост» → выберите сервер из списка или добавьте
   новый → отсканируйте QR-код со страницы компьютера либо введите адрес вручную.
3. На другом компьютере: запустите `Мост-клиент.exe`, добавьте адрес сервера (один раз),
   выберите его — чат откроется в браузере.
4. Введите имя и название комнаты → «Войти». Отправляйте сообщения и файлы (📎).

## Выбор и переключение серверов

- **Android**: при запуске и по кнопке ⚙ показывается список сохранённых серверов.
  Тап — подключиться, долгий тап — удалить из списка, «＋ Добавить сервер» — новый адрес.
  Если сервер выключен — появится сообщение об ошибке и снова список; данные никуда не
  пропадут, можно выбрать другой сервер.
- **ПК (клиент-оболочка)**: `Мост-клиент.exe` показывает список серверов при запуске и по
  кнопке ⚙; клик — подключиться (с проверкой доступности), «✕» — удалить, «🌐» — открыть
  тот же чат в браузере. Список хранится в `%APPDATA%\Мост\client.json`.
  Если окно WebView2 не создалось, клиент автоматически открывает чат в окне Edge
  (режим приложения) с тем же экраном выбора, а точную причину пишет в журнал
  `Мост-клиент.log` рядом с программой (или в `%LOCALAPPDATA%\Мост\client.log`).
- **ПК (браузер)**: просто откройте адрес сервера — тот же интерфейс, клиент не обязателен.
- Ссылка из QR-кода (`most://адрес:порт`) добавляет сервер в список приложения автоматически.

## Подключение через VPN-туннель (и проброс порта)

Сервер слушает `0.0.0.0`, поэтому доступен через **любой** сетевой адаптер — обычный
Wi-Fi, VPN, проброс порта:

- **Tailscale / WireGuard / ZeroTier и подобные mesh-VPN.** Установите VPN на ПК и телефон,
  войдите в одну сеть. Сервер сам определит VPN-адрес (адаптеры с именами
  `Tailscale/WireGuard/ZeroTier/…` и адреса `100.x.x.x` помечаются как **[VPN]**) и покажет
  отдельный QR-код. Подключение работает даже из чужого Wi-Fi и мобильного интернета.
- **Обычный VPN с доступом к подсети.** Если туннель даёт ПК адрес в подсети, доступной
  телефону (например `10.x.x.x`), просто используйте этот адрес — он тоже появится в списке.
- **Проброс порта (как в харнесе).** Если туннель пробрасывает порт с публичного хоста
  на ваш ПК: добавьте этот адрес как отдельный сервер (`хост:порт`). При HTTPS-пробросе —
  `https://…` (wss тоже заработает автоматически).
- Порт по умолчанию `8410`. Другой: `Мост.exe -port 8411`.
  Ограничить только локальной машиной: `Мост.exe -bind 127.0.0.1`.

## Сборка из исходников

Нужны Python 3 и Node.js (для загрузки инструментов).

```bat
node tools\download.mjs          :: скачать Go, JDK 17, Android cmdline-tools
powershell -File tools\setup-android.ps1   :: распаковать и поставить build-tools
python tools\make_icon.py        :: иконки
powershell -File tools\build-exe.ps1       :: dist\Мост.exe (сервер)
powershell -File tools\build-client.ps1    :: dist\Мост-клиент.exe (клиент для ПК)
powershell -File tools\build-apk.ps1       :: собрать и подписать dist\Мост.apk
node tools\test-server.mjs 8410  :: тесты (при запущенном сервере)
```

## Структура проекта

| Путь | Что это |
|---|---|
| `server/` | сервер на Go (стандартная библиотека, WebSocket реализован вручную) |
| `server/web/` | веб-интерфейс (встраивается в exe через `go:embed`) |
| `client/` | клиент подключения для ПК (Go, окно WebView2) |
| `client/third_party/` | вендоренная копия go-webview2 (MIT) с исправлением падения при отказе WebView2 |
| `android/` | исходники Android-приложения (WebView-обёртка) |
| `dist/` | готовые артефакты: `Мост.exe`, `Мост-клиент.exe`, `Мост.apk` |
| `data/` | история и файлы комнат (создаётся при работе сервера) |
| `tools/` | скрипты сборки и загрузки инструментов |

## Безопасность

Проект рассчитан на личное использование в доверенной сети: HTTP — без шифрования
(в VPN-сети это компенсируется шифрованием самого туннеля). Пароли комнат проверяются
по SHA-256-хешу и хранятся только в виде хеша (`data/rooms/<комната>/room.json`), но
передаются по сети в открытом виде — на нешифрованном HTTP это защита «от соседей по
Wi-Fi», а не от перехватчика в VPN-туннеле. Держите сервер за пределами прямого доступа
из интернета или используйте VPN.
